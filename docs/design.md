# Design DNA — 量子人才招聘网站

## 1. 视觉母题

**Human Exploration x Quantum Frontier**

从太空舱舷窗望向地球边缘的体验：深邃、克制、稀少光线、真实质感。不做未来主义的夸张霓虹，而是呈现科研机构般的可信度与人类探索前沿的沉静力量。

## 2. 页面宏观结构

### 首页（单页滚动叙事）

1. **Hero** — 全屏深空摄影背景，文字偏左下排布，非居中
2. **为什么是量子科技** — 大字号编辑式文本 + 非对称价值点
3. **四大量子技术前沿** — 编号式纵向交错条带（01-04左右交替）
4. **精选岗位** — 杂志目录式列表
5. **合作机构** — 编辑式文字列表
6. **加入量子人才网络** — 左右分栏液态玻璃 CTA
7. **Footer**

### 赛道总览 `/tracks`

纵向交错全宽板块，每个赛道左右交替偏置，不同比例栅格。

### 赛道详情 `/tracks/[id]`

1. 赛道 Hero（大编号 + 中英文名 + 描述 + CSS 线条装饰）
2. 赛道概述（左右分栏）
3. 核心技术路线（编号式列表）
4. 典型应用方向
5. 相关人才类型
6. 相关岗位（杂志目录式列表）
7. 投递与咨询 CTA（液态玻璃面板）
8. 返回入口

### 岗位中心 `/opportunities`

搜索筛选 + 杂志目录式岗位列表。

### 岗位详情 `/jobs/[id]`

左右分栏：左侧职责/要求，右侧液态玻璃投递面板。

## 3. 字体角色

| 角色 | 字体 | 用途 |
|------|------|------|
| Display | 系统无衬线粗体（PingFang SC / Noto Sans SC） | Hero 大标题、赛道编号、页面大标题 |
| Body | 系统无衬线（PingFang SC / Noto Sans SC） | 中文正文、岗位信息、描述段落 |
| Label | 系统等宽（JetBrains Mono / ui-monospace） | 编号(01-04)、英文标签、技术标签、城市/学历标签 |

Hero 英文副标题使用全大写无衬线，字间距宽（tracking-[0.2em]）。

## 4. 色彩系统

| Token | 色值 | 用途 | 面积 |
|-------|------|------|------|
| 深空背景 | `#0a0a0b` | 页面背景 | ~70% |
| 舱壁炭灰 | `#111113` / `#1a1a1d` / `#232326` | 卡片、面板、输入框 | ~20% |
| 月面白 | `#f5f5f7` | 主标题、正文 | ~8% |
| 舷窗微光 | `#a1a1aa` / `#71717a` | 次要文字、辅助信息 | ~1.5% |
| 地平线金 | `#d4a574` / `#e8c39e` | 强调色（链接、编号、急招标签） | ~0.5% |
| 液态玻璃 | `rgba(255,255,255,0.06)` | 导航、CTA、投递面板 | 关键交互 |

强调色面积严格控制在 ~5% 以内。

## 5. 液态玻璃材质规则

**仅用于以下场景：**
1. 顶部导航栏
2. Hero 核心 CTA 按钮（描边 + backdrop-blur）
3. 投递/咨询面板
4. 岗位中心筛选区

**视觉规格：**
- 背景：`rgba(255, 255, 255, 0.06)`
- 模糊：`backdrop-blur(20px) saturate(180%)`
- 边框：`1px solid rgba(255, 255, 255, 0.1)`
- 内高光：`inset 0 1px 0 rgba(255, 255, 255, 0.08)`
- 阴影：`0 4px 24px rgba(0, 0, 0, 0.3)`
- Hover：背景微亮 + 边框微亮

**禁止：**
- 所有卡片都使用玻璃拟态
- 玻璃上叠加蓝紫渐变
- 大面积毛玻璃导致文字模糊

## 6. 背景影像规则

- Hero 使用真实深空/地球边缘摄影影像
- 通过深色渐变遮罩保证文字可读（不额外添加蓝紫滤镜）
- 保留摄影本身的颗粒、光线和空间尺度
- 图片路径统一配置在 `site-config.ts` 中
- 移动端设置独立裁切策略
- 图片加载失败时使用纯深色背景兜底
- 禁止：发光量子球、紫蓝色粒子宇宙、原子图标、电路线条背景、抽象 Web3 球体

## 7. 动效规则

| 类型 | 规格 | 触发方式 |
|------|------|----------|
| 滚动渐入 | `opacity: 0→1, translateY: 24px→0`，duration 0.7-0.8s | IntersectionObserver |
| Hero 视差 | 轻微背景位移 | scroll event |
| 按钮过渡 | `transition-all 0.3s ease` | hover |
| 滚动指示器 | 小圆点 bounce 动画 | CSS animation |

**所有动效必须支持 `prefers-reduced-motion: reduce`**，降级为无动画。

## 8. 响应式规则

| 断点 | 行为 |
|------|------|
| 移动端 (<768px) | 单列布局，自然上下滑动，导航折叠为汉堡菜单，岗位详情投递面板固定底部 |
| 平板 (768-1024px) | 部分双列布局 |
| 桌面 (≥1024px) | 完整多列布局，非对称排版，hover 交互 |

- 移动端禁止劫持滚动
- 移动端禁止复杂视差
- 所有页面禁止横向溢出

## 9. 禁止使用的 AI 设计反模式

1. 紫色到蓝色、紫色到粉色的 Hero 渐变
2. 所有标题、正文和按钮全部居中
3. 三列或四列完全相同的图标功能卡
4. Logo 左侧、四个链接居中、CTA 右侧的通用导航
5. 每个 Section 都使用标题+副标题+三张卡片
6. 所有内容都放入大圆角矩形
7. 大量无意义箭头、星星、火花和渐变胶囊
8. 虚假的数据指标和社会证明
9. 页面各区域完全对称
10. 每张岗位卡片完全相同
11. 使用"赋能、引领、重新定义未来"等空泛文案堆砌
12. 发光量子球 / 原子图标 / 电路线条背景
